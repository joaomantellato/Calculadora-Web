Calculadora Web

Podemos somar, subtrair, multiplicar e dividir. tambem oferece os recursos de limpar os valores, apagar o ultimo digito, inverter o sinal e calcular porcentagem. A divisão por zero é tratada.

Escolhi JavaScript puro porque a calculadora tem uma interface pequena e funcionalidades diretas. Com ele é possível controlar os eventos dos botões e atualizar o visor sem adicionar dependências ou configurar um framework. Assim os arquivos podem ser abertos diretamente no navegador conforme pede a atividade.
